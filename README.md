# CLICKNX WhatsApp Automation

An interactive, bilingual WhatsApp enquiry-to-customer automation flow for CLICKNX.

## Included

- English and Arabic customer journeys
- Nine website-verified CLICKNX service branches
- Service-specific qualification questions
- Live website pricing tiers
- CRM lifecycle and lead-routing rules
- Appointment, quotation, follow-up, and human-handoff logic
